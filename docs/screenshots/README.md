# 界面截图

| 文件名 | 页面 | 建议截图内容 |
| ---- | ---- | ---- |
| `home.png` | http://localhost:8501 | 首页（四大服务状态卡 + 两大板块卡） |
| `job-match.png` | http://localhost:8501/岗位匹配 | 岗位检索界面（NL2SQL 查询示例） |
| `resume-score.png` | http://localhost:8501/简历评分优化 | 一次完整评估结果（总分/维度/建议） |
